## 2026-05-29 - Optimized Cursor Animation and Hover Delegation
**Learning:** High-frequency 'mousemove' listeners that directly update DOM elements cause significant main-thread overhead and redundant layout/paint cycles. Consolidating these into a single 'requestAnimationFrame' loop with 'dirty checking' (0.1px threshold) reduces stationary CPU usage to near zero. Additionally, moving from individual listeners to document-level delegation for hover states improves memory efficiency and handles dynamic elements (like AJAX-loaded products) automatically.
**Action:** Always prefer 'requestAnimationFrame' for DOM-based animations and use 'passive: true' for high-frequency input events. Implement 'dirty checking' to bypass DOM writes when no meaningful change has occurred. Use event delegation for interactive state changes on lists or dynamic grids.
