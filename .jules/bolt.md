## 2025-05-14 - Optimize cursor animation performance
**Learning:** Custom cursors often cause layout thrashing and "jank" when updates are triggered directly in high-frequency event listeners (like `mousemove`) or when CSS transitions conflict with JavaScript-driven positioning. Consolidating DOM updates into a single `requestAnimationFrame` loop and using `translate3d` with `will-change: transform` ensures the browser can optimize rendering on the GPU. Additionally, a "dirty-check" threshold prevents unnecessary style recalculations when the mouse is stationary.
**Action:** Always synchronize high-frequency DOM updates via `requestAnimationFrame`, use hardware-accelerated CSS properties, and implement dirty-checks for animated UI elements. Use event delegation to minimize the number of listeners on interactive elements.
