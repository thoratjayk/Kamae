## 2024-05-06 - [Optimized Cursor & Batch DOM Updates]
**Learning:** High-frequency event listeners like `mousemove` and multiple individual hover listeners can lead to main thread congestion and excessive memory usage. Programmatic animations should use a consolidated `requestAnimationFrame` loop with hardware-accelerated transforms (`translate3d`) and `will-change` hints to avoid layout thrashing and jitter caused by CSS transitions fighting JS updates. Document-level event delegation is essential for supporting dynamic elements (like AJAX-loaded products) efficiently.
**Action:** Always prefer document-level delegation for hover states on interactive elements. Consolidate rAF loops and use `translate3d` for smooth, performant UI animations. Use `DocumentFragment` for batching multiple DOM insertions.
