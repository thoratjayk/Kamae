## 2025-05-14 - Optimized Cursor and Interaction Delegation
**Learning:** Consolidating multiple DOM updates into a single `requestAnimationFrame` loop significantly reduces layout thrashing, especially for high-frequency events like `mousemove`. Implementing a "dirty-check" (0.1px threshold) prevents redundant DOM writes when movement is negligible. Additionally, switching from individual listeners to document-level event delegation for hover states improves memory efficiency and automatically handles dynamic content. When moving transforms from CSS to JS, it is critical to re-include percentage-based centering (e.g., `translate(-50%, -50%)`) if the JS update overrides the CSS property entirely.
**Action:** Always prefer a single rAF loop for animated UI elements. Use event delegation for hover-heavy interfaces. Ensure visual centering is preserved when manipulating transforms via JavaScript.
